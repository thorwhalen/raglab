raglab.memory#

Purpose-indexed memory: what past runs found, kept per purpose (raglab#6, stage 0).

The retrieval index is purpose-free by design; the search agent is the one layer that sees purpose (the sub-task goal, the refinement chain, the evaluator’s verdicts). Without memory, everything a run learned dies when it returns. A PurposeStore keeps the precipitate: the hits each run committed to, as ExtractionUnit s keyed by purpose, carrying their provenance ((source, artifact_id) plus the whole SearchHit.to_dict(), raw magnitudes only).

It is a RunLog sink (writes come from the run-log’s RoundRecord s, the one shared record shape) and a Memory the agent reads from before sweeping:

store = PurposeStore()
agent = make_search_agent(sources, memory=store)
agent("invoices from 2023")  # sweeps, journals what it kept
agent("invoices from 2023")  # recalls those hits; sweeps only if not sufficient

Progressive disclosure: store[purpose] is the related-purpose read. With no embedder only the same purpose (normalized text) is related; inject one (str -> vector, e.g. a vd/ir embedder) and similar purposes share their findings.

The four verbs of the design (report 14) are injected strategies; stage 0 ships two (write_strategy: ADD, or UPDATE an artifact already kept; read_strategy: relevance x importance x recency). CONSOLIDATE and DECAY are follow-ups, gated on observed need.

class raglab.memory.PurposeStore(backend=dict(), embedder=None, write_strategy=<function upsert_write>, read_strategy=<function make_relevance_recency_reader.<locals>.read>, min_relevance=0.8, clock=<built-in function time>)[source]#

Bases: MutableMapping

MutableMapping[purpose, list[ExtractionUnit]] over an injected backend.

backend maps purpose_id() to a JSON-clean record {"purpose", "embedding", "units"}: any MutableMapping (a dict, a dol store of JSON files, …). store[purpose] recalls from every related purpose (the same one, or one whose embedding is at least min_relevance cosine-similar); store[purpose] = units replaces that purpose’s units. Calling the store with a RoundRecord journals what the round kept.
