raglab#

raglab — the agentic-search / RAG orchestration layer on top of ir.

raglab turns a retrieval substrate into a Composable Search Agent (the ir_09 architecture): a small set of injected roles — Planner, Formulator, Retriever, Evaluator, Reranker, Citer — wired by a control loop whose back-edge (evaluator → reformulate) is what makes it an agent rather than a DAG. Concrete tools live at the leaves: an ir corpus becomes one Retriever via ir.as_retriever.

Quick start (the no-LLM thin slice — runs offline):

import ir
import raglab

# register ir corpora as the agent's sources, then search across them:
sources = raglab.ir_sources("skills", "reports", mode="hybrid")
agent = raglab.make_search_agent(sources)
results = agent("how do I deploy the app")      # ranked ir.SearchHits

Inject an LLM formulator (query rewrite/HyDE) and evaluator (sufficiency

  • refinement) to turn on query understanding and the back-edge. Dependency direction is one-way: raglab imports ir; ir never imports raglab.

> Fresh start (v0.2.0+). This repo took over the raglab PyPI name; the older > backend now lives at raglab_bak. Development is just beginning.

class raglab.GradedLabel(level, is_about, is_supported, is_useful, evidence_quote='', facet=None)[source]#

Bases: object

A graded verdict on one candidate (raglab#8): a level, three axes, the evidence.

level is one of the evaluator’s ordered levels (best first). The axes are Self-RAG’s: is_about (topical, ISREL), is_supported (the content actually establishes it, not a lexical mention: ISSUP) and is_useful (ISUSE). evidence_quote is a verbatim span of the candidate’s content backing the level; facet names the sub-goal it was judged against.

class raglab.Judgement(relevant, sufficient, refinement=None, graded=dict())[source]#

Bases: object

An evaluator’s verdict over a round’s results.

relevant is the kept subset; sufficient says whether to stop; a non-None refinement is the back-edge — the next sub-task to re-query with. The pass-through default returns sufficient=True and no refinement (no loop). graded is optional and additive: a graded evaluator maps each judged artifact_id to its GradedLabel; binary evaluators leave it empty.

class raglab.RoundRecord(purpose, round, goal, sources, sufficient, refinement, committed, graded=dict())[source]#

Bases: object

What one round of the loop decided: the run-log’s unit (raglab#6).

Written at the evaluator’s judgement point, it is the single record shape that per-run observability (the run-log) and cross-run memory (a purpose store) both consume. purpose is the sub-task’s original goal; goal is what this round actually searched (a refinement, from round 1 on). committed holds the hits the evaluator kept, with their raw per-source magnitudes: the pool never carries fused scores, so neither does the record.

pool_cap(limit)#

Keep at most limit hits, taking the best of each source in turn (the default).

Groups the pool by hit.source (in first-arrival order; untagged hits are one group), collapses each group to one hit per artifact (its best surface, as ir.base.best_per_artifact() does), orders the group best-first by its own raw score – sound, since one source is one score scale – and deals hits round-robin across the groups. So a late source’s strong hits are never cut before the evaluator sees them, a duplicate never takes a slot, and no score ever crosses a source boundary or is rewritten (unlike pre-ranking with the RRF reranker, whose fused ordinal scores must never re-enter the pool). The output is in that dealt order whatever the pool’s size. A missing or NaN score sorts last in its source.

Return type:

list[SearchHit]

reranker()#

Cross-source merge (the default fan-in): fuse by rank, never by raw score.

Groups the accumulated pool by hit.source and delegates the merge to ir.fuse_hits() (ir is the SSOT for hit operations): within each source raw scores order and dedup that source’s hits — one scale, sound — and across sources only ranks interact (Reciprocal Rank Fusion), so heterogeneous embedders / modes can never mis-order the merge, and colliding artifact_ids from different sources stay distinct results (identity is (source, artifact_id)).

A single-source pool (or an untagged one — hits with no source) keeps its raw scores and exactly score_reranker()’s ordering; fused, rank-derived scores only appear when there is genuinely something to fuse. Each fused hit keeps its pre-fusion magnitude as metadata["source_score"]. For per-source weights, another rrf_k, or opt-in cross-source duplicate merging, use make_rrf_reranker().

Return type:

Sequence[SearchHit]

raglab.apply_gates(proposed, content, *, levels=('core', 'strong', 'uses-tools', 'tangential', 'none'), unsupported_cap='tangential', require_evidence_quote=True, calibration_offset=None, min_quote_chars=8)[source]#

The level a judge’s proposal is allowed, after calibration and the gates.

The quote must be at least min_quote_chars long and found in content, ignoring case and runs of whitespace (judges re-case and re-wrap what they copy). calibration_offset is in levels, rounded half up, so a shift is the same at every level.

>>> label = GradedLabel('core', True, False, True, 'a DAG of tasks')
>>> apply_gates(label, 'Runs a DAG of tasks asynchronously.').level
'tangential'
>>> ok = GradedLabel('core', True, True, True, 'graph  library')
>>> apply_gates(ok, 'A graph library.').level, apply_gates(ok, 'Nothing here.').level
('core', 'tangential')
>>> apply_gates(ok, 'A graph library.', calibration_offset=1.4).level
'strong'

Evaluator

Every candidate is judged once per goal: one judge call per (source, artifact) the first time it appears in a pool for that goal, its label remembered for later rounds, so a kept hit is not re-judged (nor lost to a later failing call). Judgement.graded is keyed by artifact_id; an id found in several sources carries its best label. A reply that does not parse leaves the candidate ungraded (logged); when every judge call of a round raises, the first error is re-raised rather than returning an empty, “sufficient” round. This evaluator is for labelling a pool, not for cheap filtering.

raglab.make_llm_evaluator(*, judge=None, select_strategy='conservative', select_kwargs=None, prerank=None, prompt='A search agent is pursuing this goal:\n\n{goal}\n\nA calibrated selector reviewed the retrieved candidates and committed to the\nresults below (it abstained if this list is empty):\n\n{results}\n\nDecide whether these results are SUFFICIENT to satisfy the goal.\n- If they are, reply with exactly: SUFFICIENT\n- If they are not, reply with: INSUFFICIENT\n  then, on the next line, a single improved search query that would retrieve what\n  is still missing. Keep it a terse search phrase — no prose, no numbering.\n', max_result_chars=500, **prompt_function_kwargs)[source]#

An LLM-backed raglab Evaluator (turns on the back-edge).

Relevance is ir’s: each round the accumulated results are passed through ir.select() and the committed subset becomes the Judgement.relevant (so the LLM stays in its lane — LLM relevance is known-fragile, ir_01 §3). Sufficiency is the LLM’s: it reads the committed subset (informed by ir’s model-free sufficient hint via abstention) and decides whether the goal is satisfied. When it is not, the judge’s improved query becomes a refinement SubTask over the same sources — the back-edge.

Parameters:

  • judge (Optional[Callable[..., tuple[bool, str | None] | str]]) – an injectable (goal, results) -> (sufficient, refinement) callable (a test double, or your own router); a raw text reply is also accepted and parsed. When omitted it is built lazily on oa.

  • select_strategy (str) – ir selection strategy for the relevance decision (default "conservative" — distractor-robust).

  • select_kwargs (Mapping[str, Any] | None) – extra args forwarded to ir.select() (e.g. max_k, rel). min_score is allowed only while the round’s pool keeps raw scores (single-source, or prerank=score_reranker): an absolute floor is per-(corpus, mode, embedder), so a round whose pool was rank-fused across sources raises rather than silently mass-abstaining on ordinal RRF scores.

  • prerank (Reranker | None) – the per-round merge that puts the accumulated pool best-first (and deduped) before ir.select. Defaults to rrf_reranker() — a round’s pool can already mix sources (a SubTask spans several), so the same rank-based, scale-safe merge as the fan-in applies; single-source rounds keep raw scores. Inject score_reranker() for sources known to share one score scale.

  • max_result_chars (int) – per-result text truncation in the judge prompt.

Return type:

Evaluator

Safe fallback: any judge error returns refinement=None — the control loop’s break condition — so a failing judge can never fabricate an endless loop. Sufficiency without a refinement query is likewise treated as a stop.

raglab.make_llm_formulator(*, formulate=None, params=None, **make_kwargs)[source]#

An LLM-backed raglab Formulator.

Adapts an ir-style query formulator (str -> str | [str]) to the role contract (SubTask, source) -> [LowLevelQuery]: the sub-goal text is rewritten / expanded into one or more search queries, each wrapped as a LowLevelQuery against source.

Parameters:

  • formulate (Optional[Callable[[str], str | Sequence[str]]]) – an injectable ir-style formulator (a test double, or one you built). When omitted it is built once via ir.make_llm_formulator() (**make_kwargs are forwarded — e.g. n, prompt, rewriter); that call is offline (oa is imported lazily only when the formulator is invoked), so import raglab stays offline.

  • params (Mapping[str, Any] | None) – per-call retriever overrides (e.g. {"mode": "hybrid", "k": 5}) attached to every emitted LowLevelQuery.

Return type:

Formulator

The boundary: this returns queries, never SubTasks. ir’s formulator already falls back to identity on any failure, so the emitted list is never empty — a formulator must never make retrieval worse than the raw sub-goal.

raglab.make_search_agent(sources, *, planner=None, formulator=None, evaluator=None, reranker=None, citer=None, budget=None, pool_cap=None, run_log=None)[source]#

Build a SingleContextAgent over sources with smart defaults.

sources is a Mapping[name, Retriever] — e.g. {"skills": ir.as_retriever("skills")}, ir_sources(), or the lazy ir.retrievers() view. Every role defaults to its no-LLM thin-slice implementation, so make_search_agent(sources)("query") just works; inject an LLM formulator / evaluator to turn on rewriting and the back-edge. Pass a run_log (any callable taking a RoundRecord, e.g. list.append) to record what each round decided.

A custom Retriever must return ir.SearchHit instances (the Result alias): the loop stamps provenance (hit.source) on its output, so duck-typed hit objects raise at the tagging step.

Return type:

SingleContextAgent

raglab.score_reranker(results)[source]#

Magnitude merge: one surface per artifact, ordered by descending raw score.

Delegates to ir.base.best_per_artifact() (ir is the SSOT for hit operations): an artifact retrieved by several queries / rounds — common once the back-edge re-queries — survives once, at its highest score. Identity is (source, artifact_id), so two sources’ same-id artifacts never collapse.

A plain score sort compares raw scores across sources, which is only sound when every source shares one score scale (same embedder + mode) — it is the explicit homogeneous-sources opt-in. The default fan-in is rrf_reranker(), which never compares raw scores across sources.

Return type:

Sequence[SearchHit]
